유효숫자

측정값에서 확실한 숫자 + 마지막 어림한 숫자 1개가 유효숫자입니다.

유효숫자 개

전자저울이 154.3 g을 보일 때와 주방 저울이 154 g을 보일 때, 무엇이 다를까요?

확인값은 비슷해도 정밀도가 다릅니다. 154.3 g은 0.1 g 자리까지(유효숫자 4개), 154 g은 1 g 자리까지(3개) 믿을 수 있습니다. 측정값은 도구가 보여 주는 자리까지 그대로 씁니다. 154 g을 154.0 g이라고 쓰면 안 됩니다.
dh/dt = −(a/A)·C·√(2gh)  →  다 빠지는 시간 t = (A / Ca)·√(2h₀/g)

변인 통제

물 높이가 절반이 될 때까지의 시간은 전체의 절반일까요?

확인아닙니다. 물이 높을수록 구멍에서 나가는 속도(√2gh)가 커서 처음에 빨리 줄어듭니다. h = h₀(1 − t/T)²에서 h = h₀/2가 되는 때는 t = (1 − 1/√2)T ≈ 0.29 T. 그래프가 처음엔 가파르고 끝으로 갈수록 완만한 까닭입니다.
