물의 전기 분해 실험실

호프만 장치에 전류를 흘려 물을 수소와 산소로 나눕니다. 두 극에서 모인 기체의 부피를 재어 비를 구하고, 불꽃으로 어떤 기체인지 확인해 보세요.

2H₂O(l) → 2H₂(g) + O₂(g)

실험 순서

물에 녹일 전해질

  1. 호프만 장치에 용액을 가득 채우고 위쪽 콕을 잠급니다.
  2. 전원을 켜고 두 전극에서 기체가 모이는 모습을 지켜봅니다.
  3. 적당히 모이면 전원을 끄고 두 관의 눈금을 읽습니다.
  4. (−)극 기체 부피 ÷ (+)극 기체 부피를 구하세요. (소수 첫째 자리까지)

(−)극 · 환원 2H₂O + 2e⁻ → H₂ + 2OH⁻  → 성냥불에 '퍽' (2H₂ + O₂ → 2H₂O)
(+)극 · 산화 2H₂O → O₂ + 4H⁺ + 4e⁻  → 불씨가 다시 타오름 (O₂는 타는 것을 도움)
전체 2H₂O → 2H₂ + O₂  (전자 4개가 흐를 때 H₂ 2분자, O₂ 1분자 → 부피비 2 : 1)

생각해 보기

1. 수소는 불에 타는데 왜 성냥불을 대면 '퍽' 소리가 날까요?

확인시험관 입구에서 수소가 공기 중 산소와 섞여 한꺼번에 빠르게 타면서(2H₂ + O₂ → 2H₂O) 기체가 순간적으로 팽창하기 때문입니다. 타고 나면 물이 생겨 시험관 안쪽이 뿌옇게 흐려지기도 합니다.

2. 산소는 스스로 탈까요?

확인아닙니다. 산소는 다른 물질이 타는 것을 돕는(조연성) 기체입니다. 그래서 꺼져 가던 불씨가 산소 속에서 다시 밝게 타오릅니다. 수소 속에서는 산소가 없어 불씨가 꺼집니다.
