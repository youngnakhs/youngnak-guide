양적 관계 실험실

전자저울로 질량 변화를 재서 몰수를 구합니다. 황산 구리 결정에 들어 있는 물 분자 수와, 달걀 껍데기·칼슘제 속 탄산 칼슘의 비율을 직접 계산해 보세요. 시료 값은 실험할 때마다 조금씩 달라집니다.

CuSO₄·xH₂O(s, 파랑) → CuSO₄(s, 흰색) + xH₂O(g)

실험 순서

  1. 빈 도가니의 질량을 잽니다.
  2. 푸른 황산 구리 결정을 넣고 잽니다.
  3. 가열 → 식히기 → 달기를 질량이 더 줄지 않을 때(항량)까지 되풀이합니다.
  4. x를 구하세요. (CuSO₄ 159.6, H₂O 18.0)

CaCO₃(s) + 2HCl(aq) → CaCl₂(aq) + H₂O(l) + CO₂(g)↑

실험 순서

  1. 묽은 염산 50 mL가 든 삼각 플라스크를 저울에 올리고, 시료를 담은 약포지도 함께 올려 전체 질량을 잽니다.
  2. 시료를 플라스크에 넣고(약포지는 저울 위에 그대로) 기포가 그칠 때까지 질량을 지켜봅니다.
  3. 시료 속 CaCO₃의 질량 백분율(%)을 구하세요. (CaCO₃ 100.1, CO₂ 44.0)
    %
줄어든 질량 = 빠져나간 CO₂의 질량. 염산은 넉넉해서 CaCO₃가 모두 반응합니다. 껍데기의 나머지(단백질 막 등)는 염산과 반응해도 기체를 내지 않습니다.
