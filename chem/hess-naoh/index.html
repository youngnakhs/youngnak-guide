직접 반응 ①의 ΔH를 우회 경로 ② + ③의 합과 비교해 ΔH₁ = ΔH₂ + ΔH₃ 가 성립하는지 확인해 보세요.

2. 조건 설정 및 측정

25.0°C

반응을 선택하면 측정이 시작됩니다. (0~60초: 초기 온도 측정, 60초에 시약 투입)

3. 결과와 헤스 법칙 확인

측정된 ΔT와 측정 조건으로 q = mcΔT, ΔH = −q ÷ n 을 직접 계산해 빈칸에 입력하세요. (q는 J, ΔH는 kJ/mol 단위이고 발열 반응의 ΔH는 음수입니다.)

반응ΔT (K)측정 조건q (J)ΔH (kJ/mol)확인
ΔH₂ + ΔH₃ = kJ/mol
ΔH₁ (직접 경로) = kJ/mol
ΔH₁과의 차이 = |ΔH₂ + ΔH₃ − ΔH₁| ÷ |ΔH₁| × 100 = %

열량계의 열용량은 무시했습니다. 정답 기준값은 표준 생성엔탈피로 계산한 근삿값입니다.
