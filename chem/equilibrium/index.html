화학 평형 실험실

평형에 있는 용액과 기체에 농도·온도·압력 변화를 주고, 색이 어느 쪽으로 바뀌는지 봅니다. 르샤틀리에 원리로 예측한 다음 직접 확인해 보세요.

[Co(H₂O)₆]²⁺ (분홍) + 4Cl⁻ ⇌ [CoCl₄]²⁻ (파랑) + 6H₂O   ΔH > 0

무엇을 바꿀까

농도

온도 (시험관을 담그는 곳)

먼저 어느 쪽으로 이동할지 예측한 뒤 버튼을 누르세요. 질산 은(Ag⁺)은 Cl⁻과 만나 흰 AgCl 앙금이 됩니다.

시험관

[Co(H₂O)₆]²⁺ 많음[CoCl₄]²⁻ 많음

한 일과 결과

    2NO₂(g) (적갈색) ⇌ N₂O₄(g) (무색)   ΔH < 0

    주사기 조작

    부피 (피스톤)

    온도

    피스톤을 누르는 순간에는 같은 기체가 좁은 곳에 모여 색이 진해집니다. 그 다음 몇 초 동안 색이 어떻게 변하는지 그래프로 지켜보세요.

    기체 주사기 (옆에서 본 모습)

    -
    [NO₂] (M)
    -
    [N₂O₄] (M)
    -
    Q / K

    [NO₂] 농도 변화 (지난 20초)

    Ca(OH)₂(s) ⇌ Ca²⁺(aq) + 2OH⁻(aq)   Ksp = [Ca²⁺][OH⁻]²

    실험 순서

    수산화 칼슘을 녹일 용매

    1. 고른 용매에 Ca(OH)₂를 녹지 않고 남을 때까지 넣어 저은 뒤(포화) 거릅니다.
    2. 거른 액 25.0 mL에 페놀프탈레인을 넣습니다.
    3. 0.050 M HCl을 넣다가 붉은색이 막 사라지면 멈춥니다.
    4. 이 용매에서 Ca(OH)₂의 용해도 s(M)를 구하세요.
      M
    적정으로 구한 것은 [OH⁻]입니다. 용매에 처음부터 들어 있던 OH⁻나 Ca²⁺가 있는지 생각하세요.

    용매별 용해도 비교 (맞힌 것만 기록)

    아직 맞힌 용매가 없습니다.
    같은 이온(OH⁻ 또는 Ca²⁺)이 이미 들어 있으면 평형이 왼쪽으로 이동해 덜 녹습니다. 이것이 공통 이온 효과입니다. Ksp는 온도가 같으면 용매가 달라도 같습니다.
