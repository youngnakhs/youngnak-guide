3확인 후 게시승인되면 이 페이지에 등록돼요.

🔧 선배님 등록 도구 (관리자)

카톡으로 받은 정보를 입력해 목록에 추가하고, ‘게시용 코드 복사’로 나온 코드를 이 파일의 TUTORS 부분에 붙여넣어 저장(커밋)하면 모두에게 보입니다. 입력 중인 목록은 이 브라우저에 임시 저장돼요.

위 코드를 복사해 이 파일(senior-tutors.html)의 /* TUTORS_START */ … /* TUTORS_END */ 사이를 교체하고 저장하세요. 직접 수정이 어렵다면 이 코드를 그대로 클로드에게 보내 “등록해줘”라고 하면 됩니다.
