문항 순서
마이크 확인 필요 — 아래 버튼을 누르고 브라우저의 마이크 허용을 눌러 주세요.
아이폰 · 아이패드로 쓸 때 — 이것만 확인하세요
  1. 사파리(Safari)로 열어 주세요. 카카오톡·인스타 안에서 열면 마이크가 막힙니다 — 링크를 누른 뒤 오른쪽 아래 [사파리로 열기]를 눌러 주세요.
  2. 옆면 무음 스위치를 해제하세요(주황색이 안 보이게). 무음이면 녹음은 되는데 재생 소리가 안 납니다.
  3. 연습 중에는 화면을 끄거나 다른 앱으로 나가지 마세요. 그 순간 녹음이 멈춥니다.
  4. 공유 버튼 → [홈 화면에 추가] 해 두면 앱처럼 바로 열 수 있습니다.
  5. 이어폰(유선·에어팟)을 쓰면 목소리가 훨씬 깨끗하게 들어갑니다.
대학 하나가 한 세션입니다(각 12문항). 위 카드의 '이 설정 소요'가 실제 걸리는 시간이고, 꼬리질문을 끄면 절반 가까이 줄어듭니다. 중간에 [종료]를 눌러도 그때까지의 녹음은 남으니, 한 번에 다 하지 않아도 됩니다.
